# ai-research-assistant
AutomationTek learning projects
---
## 📌 Project 1 Overview
This project connects to the **OpenAI Chat API** and makes a simple interactive request.  
It was built step by step to learn:
- How to use Python virtual environments.
- How to manage dependencies with `requirements.txt`.
- How to safely load secrets using `.env`.
- How to write and document Python scripts with **docstrings** and **type hints**.
- How to use Git for staging, committing, and pushing code.
---

## Setup Instructions & Commands used
### 1. Clone the Repository
- git clone https://github.com/<your-username>/ai-research-assistant.git
- cd ai-research-assistant

### 2. Create and Activate Virtual Environment
- python -m venv venv
- .\venv\Scripts\activate

### 3. Install Requirements
- pip install -r requirements.txt

### 4. Adding API Key
- OPENAI_API_KEY=your_api_key_here

### 5. Running the script
- python main.py
- python main.py "What is the tallest mountain in the world?"

## Learning Goals
- Understand how to isolate project dependencies with venv.
- Learn how to stage (git add), commit (git commit), and push (git push) changes.
- Practice writing clean, documented Python code.
- Gain experience working with an API and handling environment variables securely.
